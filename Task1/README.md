## Описание текущих проблемных мест
- Много кастомизаций BI-системы поверх DWH
- Устаревший инструмент Power Builder
- Сложность интеграции новых сервисов по мере роста бизнеса компании
- Устаревший инструмент Microsoft SQL-сервер 2008 года для DWH, скорее всего не справляется с объемом данных
- В компании много различных доменов, но все данные хранятся в одном DWH
- Большое количество трансформаций данных, что в свою очередь замедляет time-to-market и приводит к снижению производительности
- Построение отчётов занимает много времени
- Шина на базе Apache Camel может быть источником проблем при масштабировании
